**Round 5 is fixed.** All 16 mutations that survived round 5 now fail named tests: N12, N13, N14, N16, N1, N2, N3, N11, P1 to P6, V1 and V2. The TEN VAD licence text matches the installed LICENSE. The baseline step was recorded. CI is green on both jobs for the head commit. AT-0.0-01 to AT-0.0-08 give the expected output when I run them.

**The verdict is still FAIL, for the same reason as rounds 4 and 5: the tests are weaker than the code.** This round I ran 50 mutations. Tests caught 31, one is equivalent in effect, and 18 survived the fast suite. One of the 18 (P13) is caught by the slow suite, so 17 survive every suite. Each survivor I list below was confirmed on a concrete input: the unmutated code gives the right answer and the mutated code gives a wrong one.
- **F39, gate parity.** Seven more rules the gate copies from the Stop hook can change without a test failing. Five of them make the gate pass edits or compromise lines that the hook rejects (`gate=[] ok=True`, while the hook reports A2, C or D1). Examples: an `ALLOW-PATTERNS-IN` line followed by a note, an approval file that does not end in `.md`, and an inline `#` comment in `PROTECTED_PATHS.txt`. EVIDENCE.md:763 says the round 5 table covers "the approval and NEVER rules in `_protected.py`". It does not.
- **F40, traceability.** The gate can stop checking that NFR IDs appear in test names, and no test fails.
- **F41, provisioning integrity.** Three guards have no test: the per-file SHA-256 check of the FireRedVAD weights, the re-check of the cached corpus archive, and the check that apt-get really installed a package. Remove any one of them and provisioning prints `PASS … sha256 verified` or `PASS installed …` when that is false.
- **F42, regression check.** If the baseline's Results table has no rows the tool can parse, the check is meant to stop with exit 2. Remove that guard and it prints `RESULT: PASS` while a baseline test fails. No test covers this.

The code is correct today in every case above. What is missing is tests that would catch a regression.
