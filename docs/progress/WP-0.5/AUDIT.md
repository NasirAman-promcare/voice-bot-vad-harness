# AUDIT — WP-0.5, round 1

Auditor: wp-auditor · Date: 2026-09-28 · Commit audited: b9c4fe7c6f95ae8d598a284dc2cfb6568b2e720b · Previous audited commit: first audit · Protocol: version 2

## Verdict: FAIL
CRITICAL: 0 · MAJOR: 5 (fixed 0, accepted as debt 0, open 5) · MINOR: 4

The shipped code did the right thing in every case I ran.
- AT-0.5-01 to AT-0.5-03 reproduce.
- The fast suite (1487 passed) and the slow suite (3 passed) pass, and CI is green on `b9c4fe7`.
- 21 of my 22 must-catch breaks fail a named test.
- The kill-and-resume test is sound, and results are byte-identical.

The verdict is FAIL because of five open MAJOR findings. None of them is a wrong result produced today. They are two record problems and three checks that can report success wrongly:
- **F01:** NFR-0.5-02 ("nothing in the lab writes to Drive except under `AQIS_LAB/`") holds for every command WP-0.5 adds and for everything the launcher runs. Three older commands still write anywhere with no Drive check: `score --out`, `pack build --out`, and `registry build` and `registry fetch`.
- **F02:** despite F01, `EVIDENCE.md`, registry row CAP-DRIVE-001 and the Colab runbook all say "every lab write" is guarded, and NFR-0.5-02 is marked DONE.
- **F03 (must-catch 5):** the "platform facts only from `aqis_lab.platform`" test is a text match. `from platform import machine as host_arch` in `runner/card.py` passes it, and so does `__import__("os").uname()`.
- **F04 (must-catch 4):** the launcher's "no logic" checker accepts any `subprocess.run([...], check=True)`. So an `if … then rm -rf …; fi` inside `bash -c` passes all 28 FR-0.5-08 tests.
- **F05:** the resume rule's refusals are tested only for the seed, the plan and the GPU type. Letting a resume go ahead on another Python version, OS, architecture or git commit passes all 20 FR-0.5-05 and FR-0.5-06 tests. The shipped code does refuse these; I probed it. No test pins that.

Four MINOR findings do not block. F06 and F07 are untested staging checks, F08 is a mislabelled run error, and F09 is DEBT-009 left with a past target.
